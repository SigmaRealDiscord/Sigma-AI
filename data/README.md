# Sigma training data

Place project-approved plain-text training files in `data/train/` (for example `data/train/ru/part-001.txt`). This directory is ignored by Git so large corpora and private data are not uploaded accidentally.

Keep a separate source manifest for every dataset: source URL or origin, language, license/permission, collection date, and preprocessing steps. Do not use personal conversations, credentials, private messages, or material without permission. Deduplicate, filter spam, and balance language representation before training.
